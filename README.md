# ห้องทดลองสะพานโครงถัก (Truss Bridge Lab)

Vue 3 + Vite — build เป็นไฟล์ static ล้วน

## รันบนเครื่อง
```bash
npm install
npm run dev        # เปิด http://localhost:5173
```
ต้องใช้ Node.js 18 ขึ้นไป

## Deploy บน Render
New → **Static Site** → ตั้งค่า
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

## แนวคิดของแบบจำลอง
- ค่าที่นักศึกษาใส่ (ชนิด, มุม, แรง, ดึง/ดัน) ถูกนำไปเป็นแรงที่ชิ้นส่วนกระทำต่อจุดต่อ/คาน
- ด่าน 1-3: ตรวจ ΣFx = 0, ΣFy = 0 ที่จุดต่อ O ด่าน 4: ตรวจ ΣM รอบบานพับ O = 0 และแรงที่บานพับ
- ถ้าไม่สมดุลหรือชิ้นส่วนเกินกำลัง จะพังตามกลศาสตร์ (a = ΣF/m, α = M/I): สลิงขาด, สลิงหย่อน (ถูกดัน), เหล็กโก่งเดาะ, บานพับหลุด, จุดต่อเหวี่ยง, คานหมุนขึ้น/ลง
- ปรับตัวเลขกำลังของวัสดุ น้ำหนัก และตำแหน่งได้ที่ `src/engine.ts` (อาร์เรย์ `levels`)
